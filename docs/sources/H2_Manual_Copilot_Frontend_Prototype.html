Maintenance Manual · Cooling System

7.4 Error Code E104

This section describes the inspection sequence for cooling-system temperature alarms on the HX-100 electrolyzer.

Referenced passage

E104 — Cooling system temperature abnormal.

Inspect coolant level, circulation pump operating state and temperature sensor connection before escalating to component-level diagnosis.

Inspection sequence

1. Confirm coolant level is within the documented operating range.

2. Confirm the circulation pump is running and no flow alarm is present.

3. Inspect temperature sensor connection and signal continuity.

Safety: Do not bypass interlocks or alter protected operating parameters while diagnosing the alarm.
