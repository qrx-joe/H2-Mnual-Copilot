# ADR-0002 核心问答链路使用显式管线，不引入 Agent 框架

- 状态：已接受
- 日期：2026-08-19
- 来源：技术规范 ADR-003、§110

## 背景

RAG 主流程（retrieve → rerank → generate → verify）是确定性工作流。多 Agent 协作框架（CrewAI/AutoGen 类）会增加不可预测性与调试成本，且 PRD 明确 MVP 砍掉多 Agent（PRD §57）。

## 决策

问答与接入链路实现为显式管线代码；每一步可独立测试、观测与替换。不引入任何 Agent 编排框架。

## 后果

- 行为可预测、可逐步调试；每步耗时与失败可单独归因（配合 trace 结构，技术规范 §72）。
- 未来需要更复杂编排时再评估，且必须先过 golden dataset 回归（技术规范 §83）。
