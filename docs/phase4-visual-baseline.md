| 缺陷 | 现象 | 根因 | 修复 |

## 4. 已知视觉简化（Phase 5/6 处理）

1. Source Viewer 为模拟 DOM 页面（同原型）；真实 PDF 渲染（PDF.js）在 T-020。
2. 管线进度卡的当前步高亮动画、页面切换进场动画等微动效保留为 CSS 类，未逐帧比对原型。
3. 缩略图列为静态示意（4 张占位）；真实缩略图随 PDF.js 接入。
4. toast 图标用 clip-path 绘制（等价视觉），未内联原型的 SVG symbol 全集。
